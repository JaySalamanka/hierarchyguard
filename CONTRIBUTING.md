# Contributing

This repository is a private clean-room launch candidate licensed under
MPL-2.0. External contributions are not currently accepted. The source license
does not itself open a contribution channel or authorize maintainers to publish
the repository.

Before public contribution opens, the owner will approve contributor terms, a
support channel, review policy, synthetic-data policy, and public/private
boundary rules. No contributor should submit customer files,
proprietary rulebooks, real asset identifiers, prompts, screenshots, generated
media, secrets, or material copied from another product.

Internal changes must use a branch and pull request, keep the Action offline,
add tests, rebuild `dist/`, inspect `npm pack`, and pass both public and private
boundary scanners.
