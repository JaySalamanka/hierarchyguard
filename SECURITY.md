# Security policy

AssetTree CI is a private launch candidate and has no supported public release yet.

Do not report a vulnerability through a public issue or include customer data,
repository data, credentials, or exploit payloads in an unapproved channel. While
the repository is private, authorized reviewers should contact the owner through
their existing private access path.

No public security email has been designated. As part of the controlled public
transition, GitHub private vulnerability reporting must be enabled, tested, and
monitored before any announcement or release. Supported versions, reporting
instructions, response posture, and disclosure expectations will be published
then. Security advisories must never be used for customer files or paid-audit
intake.

The runtime is intended to operate without networking, secrets, write
permissions, telemetry, or execution of customer content. A regression in any of
those boundaries is considered security-sensitive.
